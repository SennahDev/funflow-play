# Changelog

## 0.1.0 – first release

- Library: pick a folder, videos and funscripts are matched automatically (subfolders too),
  thumbnails, 4K/HDR badges, search, sort, resume position.
- Player: hardware-decoded playback with HDR, double-tap skip, jump to next/previous
  action, seek bar with script heatmap, device on/off chip.
- Scripts: stroke scripts are converted into a smooth speed, intensity scripts are played
  directly; automatic detection with per-video override.
- Toys via Intiface Central (Buttplug protocol v4); minimum/maximum speed mapping,
  latency compensation. The toy always stops when the app goes to the background.
